Local LLM runtime

Local AI,
brewed on your machine.

TeaCat is an open-source runtime by Tyxen that downloads GGUF models and runs them offline with its own transformer engine, written from scratch in Go. No cloud, no telemetry, no llama.cpp underneath.

Get TeaCat on GitHub Read the docs 
$ teacat pull qwen2.5:0.5b
success: qwen2.5:0.5b (379.4 MB)

$ teacat run qwen2.5:0.5b "Hello!"
Hello! How can I help you today?

$ teacat serve
TeaCat 0.1.0 listening on :11434

Everything is yours to read

TeaCat implements the whole stack: file format, quantization, tokenizers, attention, sampling, storage and HTTP APIs.

🧠

From-scratch engine

RMSNorm, RoPE, grouped-query attention with a KV cache, SwiGLU feed-forward layers and a sampler. Pure Go, no cgo.

📦

GGUF + quantization

Reads GGUF v2/v3 and supports F32, F16, BF16, Q8_0, Q4_0/1, Q5_0/1 and the K-quant family including Q4_K and Q6_K.

🔌

Two APIs, one server

Drop-in Ollama endpoints and OpenAI-compatible chat completions with streaming, so existing clients just work.

⬇️

Model manager

Pull from the Ollama registry with SHA-256 verification, import a local GGUF, or download a direct URL. Stored under ~/.teacat.

💬

Chat templates

ChatML, Llama 3/2, Phi-3, Gemma and Command-R are detected automatically from model metadata.

🪶

Small and portable

A single binary on Windows, Linux and macOS. No runtime, no service mesh, no account.

Brew your first model

Prebuilt binaries for Windows, Linux and macOS (amd64 and arm64), or build from source with Go 1.22+.

Build

.\build.ps1 on Windows, ./build.sh on Linux or macOS, or go build -o teacat ./cmd/teacat.

Pull

teacat pull qwen2.5:0.5b fetches a quantized instruct model into ~/.teacat.

Chat

teacat run qwen2.5:0.5b starts a streaming terminal chat.

Serve

teacat serve exposes http://127.0.0.1:11434 for your own apps.

Point your tools at it

TeaCat speaks the same protocols as the tools you already use.

Ollama API

POST /api/chat
{
  "model": "qwen2.5:0.5b",
  "messages": [
    { "role": "user",
      "content": "Hello!" }
  ],
  "stream": false
}

POST /v1/chat/completions
{
  "model": "qwen2.5:0.5b",

      "content": "Hello!" }

  "stream": true

Built by Tyxen

TeaCat is designed and developed by Tyxen, who wanted local language models to feel as simple as making tea: one command, everything on your own machine, and a codebase small enough to read end to end. The name TeaCat combines a warm cup with a curious cat — quiet, local and always up for a chat.
